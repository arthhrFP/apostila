Capítulo 48

使役形（causativo） ・ 使役形 + ていただけませんか

使役
しえきけい
Voz causativa — "fazer/deixar alguém fazer algo"
1 Quando é utilizada

A forma causativa expressa que alguém causa ou permite que outra pessoa faça uma ação — seja por autoridade (fazer/obrigar) ou por concessão (deixar/permitir).

Use quando: descreve pais mandando filhos fazerem algo, professores dando tarefas a alunos, chefes designando trabalho a subordinados, ou alguém permitindo que outra pessoa faça algo.

Evite quando: a pessoa está simplesmente fazendo algo por conta própria, sem nenhuma relação de causa/permissão envolvida — nesse caso, o verbo comum (não causativo) é suficiente.

2 Formação — passo a passo por grupo
GrupoRegraExemplos
I（五段）Som final -u → -a + せる書く→書かせる／読む→読ませる／話す→話させる／待つ→待たせる
I（terminados em う sozinho)う → わせる (não あせる)買う→買わせる／使う→使わせる
II（一段）Remove る, adiciona させる食べる→食べさせる／見る→見させる／起きる→起きさせる
III（不規則）する→させる／来る→来させるする→させる／来る→来させる（くる→こさせる）

Conjugações do causativo (uma vez formado, o verbo causativo conjuga como um verbo do Grupo II comum):

FormaExemplo（書く → 書かせる）
Presente afirmativo書かせる
Presente negativo書かせない
Passado afirmativo書かせた
Passado negativo書かせなかった
Forma て書かせて
Forma polida書かせます
3 Explicação detalhada

Uma vez formado, o verbo causativo sempre conjuga como um verbo do Grupo II (一段) — não importa de qual grupo ele veio originalmente. Por isso 書かせる (que veio de um verbo do Grupo I) conjuga igual a 食べさせる (que veio do Grupo II): ambos seguem o mesmo padrão de negativo/passado/forma て.

Sを × Sに — a regra mais importante desta gramática

A partícula que marca a pessoa "causada" depende do tipo de verbo:

Tipo de verboPartícula do "causado"Exemplo
Intransitivo（自動詞）を子供を公園に行かせる。
Transitivo（他動詞）に（+ を no objeto）子供に野菜を食べさせる。

Pense assim: se o verbo já "usa" o を para seu próprio objeto (como 食べる usa を para "o que é comido"), a pessoa causada muda para に, porque o を já está ocupado. Se o verbo é intransitivo e não tem objeto próprio, o を fica livre para marcar a pessoa causada.

"Fazer" × "Deixar"

O mesmo verbo causativo pode significar tanto obrigar ("fazer alguém fazer") quanto permitir ("deixar alguém fazer") — depende do contexto. Palavras como 好きなだけ (o quanto quiser) ou 自由に (livremente) sinalizam permissão; a ausência dessas pistas, especialmente com tarefas indesejáveis, tende a soar mais como obrigação.

Quando pode soar autoritário

Como o causativo coloca o falante na posição de quem "causa" a ação de outra pessoa, usá-lo diretamente com superiores, desconhecidos ou em tom muito direto pode soar rude ou arrogante — como se o falante estivesse se colocando numa posição de autoridade sobre a outra pessoa.

✓ Observações importantes
  • O mesmo verbo causativo pode significar "fazer" ou "deixar" — preste atenção às pistas ao redor (好きなだけ, 自由に = permissão).
  • Verbos causativos conjugam sempre como verbos do Grupo II, independentemente do grupo original.
  • Muito usado em contextos de hierarquia: pais-filhos, professores-alunos, chefes-subordinados.
  • Existe também a forma causativa-passiva (させられる, "ser forçado a fazer algo"), mas ela não é o foco deste capítulo.
訂正
! Erros comuns
  • Confundir quando usar を e quando usar に. Lembre-se: verbo intransitivo = causado com を; verbo transitivo = causado com に (e を continua no objeto).
  • Esquecer a exceção dos verbos terminados em う sozinho. Errado: 買あせる. Certo: 買わせる.
  • Usar causativo de forma direta com superiores, o que pode soar rude — nesses casos, prefira a estrutura educada da próxima gramática (causativo + ていただけませんか).

使役+
〜させていただけませんか
"Você poderia me deixar fazer...?" — pedido educado de permissão
1 Quando é utilizada

Combina o causativo com ていただけませんか (um pedido extremamente educado de "poderia...?") para pedir permissão para o próprio falante fazer algo — a forma mais polida de dizer "seria possível me deixar fazer X?".

Use quando: quer pedir permissão educadamente para fazer algo você mesmo — sair mais cedo, usar algo, ter um tempo para pensar.

Evite quando: quer pedir que OUTRA pessoa faça algo — essa estrutura é só para pedir permissão para si mesmo.

2 Formação
PadrãoExemplo
V causativo (forma て) + いただけませんか帰らせていただけませんか
3 Explicação detalhada

いただく é a forma humilde de もらう (receber). Então させていただけませんか significa literalmente algo como "eu não poderia receber [de você] o favor de ser deixado fazer X?" — uma estrutura em camadas: causativo (eu sendo deixado/permitido a fazer X) + recebimento humilde (いただく) + pergunta negativa educada (けませんか) = o máximo de polidez para pedir permissão.

Pedido educado de tempo/espaço para decidir.

あした やすませて いただけませんか。

Pedido formal de folga a um superior.
質問させていただけませんか。

Pedido educado antes de interromper com uma pergunta — comum em reuniões e aulas.
✓ Observações importantes
  • É uma das formas mais educadas de pedir permissão em japonês — muito usada em ambientes de trabalho formais.
  • Sempre usada quando o próprio falante é quem quer fazer a ação.
  • Pode ser encurtada para させてください (menos formal, mas ainda educada) ou させてもらえませんか (levemente menos formal que いただけませんか).
訂正
! Erros comuns
  • Usar essa estrutura para pedir que OUTRA pessoa faça algo — させていただけませんか é especificamente para pedir permissão para VOCÊ MESMO.
  • Esquecer de formar corretamente o causativo antes de adicionar ていただけませんか.
  • Usar em contextos excessivamente casuais, onde soa formal demais — entre amigos próximos, させて? já basta.
