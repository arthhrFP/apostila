Grandes distinções

のに × が × ても

のに sempre carrega emoção (surpresa/frustração) e descreve um fato real; が é neutro; ても é para o hipotético/geral ("mesmo que").

天気がいいのに、寒いです。天気がいいですが、寒いです。雨が降っても、行きます。
Estranho/incomodado (fato real)Constatação neutraDecisão que não muda (hipotético)
場合 × とき

地震の場合は…（regra objetiva, uma entre várias situações）× 日本にいたとき…（um momento específico, mais neutro/cotidiano）

たところです × たばかりです

ところ = segundos/minutos, ligada ao contexto imediato. ばかり = pode ser dias/semanas, desde que ainda pareça recente para o falante.

はず × よう × でしょう

はず = lógica/evidência concreta (mais certeza). よう = impressão pessoal, várias evidências acumuladas. でしょう = suposição geral, certeza variável.

そうです（伝聞） × そうです（様態） × と言っていました

伝聞 = informação de terceiros, forma COMPLETA (だ mantido). 様態 = impressão visual imediata, forma CORTADA (sem い/だ). と言っていました = repetição das palavras exatas de alguém.

尊敬語 × 謙譲語

Pergunta de ouro: "de quem é a ação nesta frase?" Do ouvinte/terceiro respeitado → 尊敬語 (eleva). Do próprio falante → 謙譲語 (rebaixa).

Dicas para memorizar

  • 場合 → pense em manual de instruções: formal, objetivo, "em caso de X, faça Y".
  • のに → se a frase não tem NENHUMA emoção por trás, provavelmente não é のに.
  • ところ → um "zoom" no cronômetro: segundos, não dias.
  • ばかり → "recência com folga": aceita dias/semanas, desde que ainda pareça novo.
  • はず → sempre precisa de uma RAZÃO por trás. Sem razão, não é はず, é かもしれない.
  • そうです（伝聞） → você está "citando" uma frase inteira ouvida — por isso ela entra completa, com だ e tudo.
  • そうです（様態） → corta a palavra (おいしそう, não おいしいそう) porque é só uma pista visual rápida.
  • ようです → não é uma pista só, são VÁRIAS pistas somadas até virar uma conclusão.
  • ～がします → a sensação "chega até você" — você não foi atrás dela.
  • 使役形 → quem tem poder/proximidade faz o outro agir. Intransitivo = を; transitivo = に.
  • 尊敬語 → ELEVA o outro. Nunca fale de si mesmo assim.
  • 謙譲語 → REBAIXA você mesmo. Nunca fale do interlocutor assim.

Erros comuns — os 8 mais importantes

総復習
  1. Esquecer o な antes de 場合／のに／ようです／はずです com adjetivos な e substantivos.
  2. Confundir a formação de そうです（伝聞, forma completa）com そうです（様態, forma cortada）.
  3. Usar 尊敬語 para si mesmo ou 謙譲語 para o interlocutor — a troca mais grave de todas.
  4. Errar a partícula do causativo: を para verbo intransitivo, に para verbo transitivo.
  5. Conjugar verbos especiais de keigo como regulares (いらっしゃります em vez de いらっしゃいます).
  6. Usar のに numa frase sem nenhuma carga emocional real.
  7. Confundir ところ (segundos) com ばかり (pode ser dias).
  8. Usar はず como se fosse um simples chute, sem nenhuma base lógica por trás.
